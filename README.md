# Q-Go Fuel

A UX/UI case study exploring how digital experiences can improve the fuel station journey.

## About the Project

Q-Go Fuel is a conceptual product that I designed to address a common problem many commuters face—long queues and a slow payment process at fuel stations.

The idea came from observing how much time is lost during refuelling, especially during peak hours. This project explores how a digital queue system, integrated payments, and a simple mobile experience could make the process faster and less stressful for both customers and fuel station staff.

Rather than focusing only on the interface, this case study documents my complete design thinking process, from identifying the problem to developing a practical solution.

## The Problem

Fuel stations often become crowded during busy hours. Customers spend unnecessary time waiting in line, payments can be slow, and employees have to manage both vehicles and transactions at the same time.

These small frustrations add up and affect the overall experience.

---

## My Approach

The goal of Q-Go Fuel was to explore a simpler way to refuel.

The proposed experience allows users to:

- Join a digital queue before reaching the station
- Complete payments digitally
- Receive invoices instantly
- Reduce waiting time
- Create a smoother experience for both customers and staff

---

## Design Process

This project was developed using a user-centred design approach.

The process included:

- Understanding the problem
- Researching existing solutions
- Identifying user needs
- Creating user flows
- Designing wireframes
- Building a visual design system
- Designing high-fidelity mobile interfaces
